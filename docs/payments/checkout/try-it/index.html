Wallets & signaturesNew conceptLearn more →
A wallet is a keypair: a public address that anyone can pay, and a private key that signs approvals and never leaves the device.
Like:An account number plus a password that only ever approves things and never gets sent anywhere.

What just happened

Your click became a transaction. The panel above (it appears after step D) is the real anatomy of a payment: an ID, who signed it, what moved, and the fee.

TransactionsNew conceptLearn more →
A transaction is a signed request to change the shared ledger. It either fully happens or doesn't happen at all, and once confirmed anyone can look it up.
Like:A signed, atomic database write with a public audit log.
Token accountsNew conceptLearn more →
Wallets don't hold tokens directly. Each token (USDC, or your own asset) gets a small account owned by the wallet, and transfers move between these accounts.
Like:A separate sub-account per currency at a bank.

Design notes

Why this page looks the way it does. These are for reviewers, not part of the product. Full evidence and sources: Docs Research.

WhyPrinciple 4, use it, then show it live. The developer goes through the product as a customer before seeing any code, then reads their own transaction, then sees the real network doing the same thing. The Explorer is taught on a transaction they made, which means more than a sample one would.
Risk / dependencyPrinciples 3 and 4 pull against each other. Receiving a stablecoin normally means installing a wallet app, which is an install before first success. This page uses an in-page devnet wallet (a burner key in browser storage) plus a faucet. That's a hard dependency for the Playground team: a hosted devnet USDC faucet that won't rate-limit a focus group. Connect your own wallet should be an option, never the default.
WhyThree concepts are introduced, each in two sentences with a web2 analogy: wallet, transaction, token account. Devnet appears only as an inline chip. Every card links to the matching concept page, which shows the same text.
WhyThe shop pays the network fee here, so a first-time customer never has to hear about SOL. The production version of this decision is taught in Go live (fee sponsorship).

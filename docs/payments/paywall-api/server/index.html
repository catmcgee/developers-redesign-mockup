Add it to your server

Install the middleware in your own app, pick a facilitator, and pay for your endpoint from a real client.

Copy MarkdownOpen ▾~10 min

1. Install

npm install x402-express @solana/kit

2. Protect your routes

server.ts
import { paymentMiddleware } from "x402-express";

app.use(paymentMiddleware(process.env.PAY_TO, {
  "GET /api/forecast": { price: "$0.01", network: process.env.NETWORK }, // "solana-devnet" → "solana"
  "POST /api/summarize": { price: "$0.05", network: process.env.NETWORK },
}, { url: process.env.FACILITATOR_URL }));
import { paymentMiddleware } from "x402-next";

export const middleware = paymentMiddleware(process.env.PAY_TO, {
  "/api/forecast": { price: "$0.01", network: process.env.NETWORK },
}, { url: process.env.FACILITATOR_URL });

export const config = { matcher: ["/api/:path*"] };

3. Pay from a client

client.ts
import { wrapFetchWithPayment } from "x402-fetch";
import { createKeyPairSignerFromBytes } from "@solana/kit";

const signer = await createKeyPairSignerFromBytes(loadKey("client.json"));
const pay = wrapFetchWithPayment(fetch, signer, { maxPerRequest: "$0.05" });

const res = await pay("http://localhost:3000/api/forecast"); // handles the 402 for you
console.log(await res.json());
RPCNew conceptLearn more →
RPC is the HTTP/JSON API your code uses to read from and send to the network. Use public endpoints for testing and a provider in production.
Like:A hosted database endpoint, with RPC providers in the role of AWS or Supabase.
Confirmation & finalityNew conceptLearn more →
A transaction goes from processed to confirmed (~0.4 s) to finalized. Confirmed is enough for most orders. Finalized can't be reversed, and takes longer.
Like:Pending → authorized → settled.

Facilitators usually settle at confirmed, which adds roughly half a second to the first paid request. For high-frequency clients, cache a short-lived session after the first payment.

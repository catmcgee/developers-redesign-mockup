All concepts

The basics
Wallets & signaturesA wallet is a keypair: a public address that anyone can pay, and a private key that signs approvals and never leaves the device.
The basics
SignaturesEvery transaction is signed by the wallets it spends from.
The basics
TransactionsA transaction is a signed request to change the shared ledger.
The basics
AccountsEverything on Solana (balances, tokens, programs, app data) lives in accounts: records at an address, each with an owner that is allowed to change it.
The basics
Devnet & mainnetDevnet is a free public test network that behaves like the real one (mainnet), with play money.
Tokens
Token accountsWallets don't hold tokens directly.
Tokens
Mints & authoritiesA mint account defines a token: its supply, its decimals, who may create more (mint authority) and who may freeze holders (freeze authority).
Tokens
Token extensionsOptional features of the Token-2022 program, such as metadata, pausing, default-frozen accounts and transfer hooks, switched on per mint.
Costs & speed
FeesEvery transaction pays a small flat network fee, currently a fraction of a cent, whatever the amount.
Costs & speed
Fee sponsorshipBy default, whoever sends a transaction needs a little SOL to pay its fee.
Costs & speed
Rent (storage deposit)Every account holds a small refundable deposit for the space it takes up.
Costs & speed
Confirmation & finalityA transaction goes from processed to confirmed (~0.4 s) to finalized.
Building
RPCRPC is the HTTP/JSON API your code uses to read from and send to the network.
Building
ProgramsPrograms are code deployed to the network that owns and updates accounts.
Building
Program-derived addressesA PDA is an address derived from a program plus some seeds.
Building
Cross-program callsA cross-program call (CPI) is one program calling another inside the same transaction, the way your program would call the Token program to move tokens.

Design notes

Why this page looks the way it does. These are for reviewers, not part of the product. Full evidence and sources: Docs Research.

WhyThe coverage table is generated from the paths. Every concept card in a path registers itself, so the table can't drift from the content. A concept that no path introduces shows up as a gap.
WhyWriting programs, PDAs and CPI are uncovered in Wave 1. That's the real trade-off behind the open decision about swapping in a program-writing path. I'd still keep Wave 1 as proposed: web2 developers build on existing programs long before they write their own, and today's Quick Start covers the gap from More use cases → Write your own program.
Vs. todayRenamed from Core Concepts. The URLs under /docs/core/* can stay; only the label and the opening card change.

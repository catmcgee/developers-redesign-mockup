Run it from your machine

Create the same asset from your terminal against devnet, then approve a holder so they can receive it.

1. Install and create a key

npm install @solana/kit @solana-program/token-2022
npx @solana/keygen new -o issuer.json     # your issuer wallet
# get free devnet SOL for fees and rent: https://faucet.solana.com
Rent (storage deposit)New conceptLearn more →
Every account holds a small refundable deposit for the space it takes up. Opening a USDC account for a new customer costs about 0.002 SOL, which comes back if the account is closed.
Like:A refundable deposit on a storage locker.

2. Create the mint

create-asset.ts
import { createSolanaRpc, createKeyPairSignerFromBytes } from "@solana/kit";
import { createMint } from "@solana-program/token-2022";

const rpc = createSolanaRpc("https://api.devnet.solana.com");
const issuer = await createKeyPairSignerFromBytes(load("issuer.json"));

const mint = await createMint(rpc, {
  payer: issuer, decimals: 6, mintAuthority: issuer.address, freezeAuthority: issuer.address,
  extensions: { metadata: { name: "Lisbon Solar Fund", symbol: "LSF" }, pausable: true, defaultFrozen: true },
});
console.log("mint", mint);
let mint = create_mint_with_extensions(&rpc, &issuer, MintConfig {
    decimals: 6,
    metadata: Some(("Lisbon Solar Fund", "LSF")),
    pausable: true,
    default_frozen: true,
})?;
println!("mint {mint}");
RPCNew conceptLearn more →
RPC is the HTTP/JSON API your code uses to read from and send to the network. Use public endpoints for testing and a provider in production.
Like:A hosted database endpoint, with RPC providers in the role of AWS or Supabase.

3. Approve a holder

New token accounts start frozen. Approve an investor by thawing their account directly, or let Token ACL do it automatically for addresses on your allowlist.

approve.ts
await thawAccount(rpc, { mint, owner: investorAddress, freezeAuthority: issuer });

What you just created

AccountsNew conceptLearn more →
Everything on Solana (balances, tokens, programs, app data) lives in accounts: records at an address, each with an owner that is allowed to change it.
Like:Rows in one global key-value table, where each row says which service may write to it.
Mints & authoritiesNew conceptLearn more →
A mint account defines a token: its supply, its decimals, who may create more (mint authority) and who may freeze holders (freeze authority).
Like:The class definition plus the admin roles for your asset.
ProgramsNew conceptLearn more →
Programs are code deployed to the network that owns and updates accounts. Most apps call existing programs, such as the Token program, rather than writing their own.
Like:A hosted, shared API that everyone calls and nobody can change under you.
Token extensionsNew conceptLearn more →
Optional features of the Token-2022 program, such as metadata, pausing, default-frozen accounts and transfer hooks, switched on per mint. Most must be chosen when the mint is created.
Like:Feature flags you have to set when you create the table.

Choose extensions before you launch. Most of them can't be added to a mint after it's created. Decide on pause, default state and a permanent delegate up front, or plan to migrate.
